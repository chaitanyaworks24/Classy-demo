# Product Requirements Document --- Interior Studio Website

## 1. Product Overview

### Product Name

**\[Studio Name\] --- Premium Interior Design Website**

### Product Purpose

Build a premium, conversion-focused website for an interior design
studio that functions as:

1.  A **high-end digital portfolio** that the studio can directly share
    with prospective clients.
2.  A **trust-building brand experience** that communicates the studio's
    design quality, professionalism and execution capability.
3.  A **lead-generation engine** designed around consultations and
    estimate requests.
4.  A **quote/estimate calculator** that captures project requirements
    and produces a useful budget estimate.
5.  A **resource hub** that converts visitors who are not yet ready to
    speak with a designer.
6.  A structured foundation for future analytics, lead tracking and
    CMS-driven project management.

The website should not feel like a generic interior-design template. It
should feel like a **premium design studio's digital showroom**.

------------------------------------------------------------------------

# 2. Core Selling Proposition

The website should communicate four major strengths:

### 2.1 High-End Brand Experience

The visual language, typography, spacing, photography, interactions and
motion should feel premium and intentional.

### 2.2 Custom Studio Branding

The website must be visually branded around the specific studio rather
than looking like a reusable template.

The studio's: - logo - name - colour palette - typography -
photography - design philosophy - awards / credentials - location -
contact details

should be incorporated consistently.

### 2.3 Organised, Professional Portfolio

Projects are the strongest proof of capability.

The portfolio should be structured so well that a studio owner can
confidently send the website link directly to a client instead of
sending a separate PDF portfolio.

### 2.4 High-Conversion Journey

Every major page should give the visitor a logical next action: -
Explore projects - Talk to a designer - Get an estimate - Download a
guide - View services - Enquire about a project

The website should sell through **proof + clarity + low-friction CTAs**,
not aggressive sales copy.

## Overall Design Language

-   Luxury

## Approved V1 Visual Baseline — Stitch-Inspired Direction

### Reference

The approved visual direction is based on the supplied Google Stitch reference:

https://stitch.withgoogle.com/projects/14098697700234006017

Stitch is being used as the visual-language reference for the website. It should influence the visual treatment, composition, typography, spacing, color relationships, image presentation, and overall interaction feel.

The Stitch reference does NOT replace or override the product requirements, business structure, navigation, content architecture, portfolio categories, service structure, calculator requirements, pricing logic, lead capture requirements, or other requirements defined in this Product document.

### Approved Visual Language

The website should feel:

- Editorial
- Architectural
- Sophisticated
- Warm
- Minimal
- Confident
- Quietly luxurious
- Human
- Image-led
- Premium without being flashy

The design should feel closer to a premium interior-design editorial publication / digital showroom than a conventional business website.

Avoid:

- Generic corporate layouts
- SaaS-like interfaces
- Over-rounded UI
- Excessive cards
- Loud gradients
- Excessive animations
- Template-looking sections
- Stock-photo-heavy presentation
- Dense dashboards
- Excessive shadows
- Decorative UI that does not improve the experience

### Approved Color System

The V1 visual baseline intentionally adopts the following core color relationships from the Stitch reference.

| Token | Hex | Usage |
|---|---|---|
| Ivory Background | `#F9F7F2` | Primary page background |
| Charcoal Text | `#1A1A1A` | Primary text, headings, dark sections |
| Heritage Gold | `#C5A059` | Accent, eyebrow details, borders, selected states, premium CTA details |
| Stone | `#E5E2DA` | Secondary surfaces, dividers, subtle backgrounds |
| White | `#FFFFFF` | Image/content surfaces and high-contrast areas |

The palette should remain restrained.

Gold should be used as an accent rather than as a dominant fill color.

The overall visual impression should remain warm, architectural, and premium.

### Approved Typography

The V1 typography system uses two complementary fonts:

#### Playfair Display

Use for:

- Hero headlines
- Major page headings
- Editorial statements
- Project titles
- Large section headlines
- High-impact portfolio storytelling

Playfair Display provides the editorial / luxury character of the experience.

#### Inter

Use for:

- Navigation
- Buttons
- Body copy
- Metadata
- Labels
- Filters
- Forms
- Calculator UI
- Supporting information
- Utility text

Inter provides clarity and usability.

The combination of Playfair Display + Inter should create the primary visual contrast between editorial storytelling and functional information.

### Typography Hierarchy

The visual hierarchy should generally follow this structure:

1. Large editorial headline
2. Supporting statement / body copy
3. Project or section title
4. Metadata / eyebrow label
5. Supporting details
6. CTA

Small uppercase eyebrow labels may use Inter with increased letter spacing.

Typography should have generous line-height and sufficient breathing room.

### Layout Philosophy

The layout should follow an editorial, architectural composition rather than a standard marketing-template structure.

Preferred characteristics:

- Generous whitespace
- Large photography
- Strong horizontal rhythm
- Asymmetric layouts where appropriate
- Editorial image grids
- Large section transitions
- Fine 1px borders
- Controlled geometric structure
- Clear alignment
- Strong visual hierarchy
- Large image-to-text relationships
- Intentional negative space

Avoid filling every available space.

Whitespace is an important part of the brand experience.

### Photography Priority

Photography is one of the strongest visual elements of the website.

The hierarchy should generally be:

**Photography → Typography → Whitespace → Content → UI controls**

Interior images should be allowed to breathe and should often occupy significant visual real estate.

Where supplied project assets are available, they should be preferred over random stock imagery.

Portfolio presentation should feel like a curated interior-design editorial rather than a generic image gallery.

### Page Rhythm

Pages should use a calm vertical rhythm.

Sections should not feel compressed together.

Major sections should have substantial spacing between them, especially:

- Hero → introduction
- Introduction → portfolio
- Portfolio → services
- Services → process
- Process → CTA
- CTA → footer

The visual rhythm should make the website feel premium through restraint rather than through excessive decoration.

### Navigation

The navigation should remain lightweight and understated.

It should provide access to:

- Home
- About Us
- Portfolio
- Our Services
- How It Works
- Contact
- Get Free Quote / Calculator

The header should not visually dominate the page.

The primary CTA should remain clear without making the navigation feel like a SaaS dashboard.

### CTA Treatment

CTAs should feel architectural and premium.

Preferred characteristics:

- Clean rectangular geometry
- Minimal corner radius
- Strong typography
- Controlled use of gold
- Clear hover states
- Adequate whitespace
- No excessive shadows
- No exaggerated gradients

Primary conversion actions include:

- Purposeful

- Consistent across the site

### Core Rule

The Stitch reference controls the **visual direction**.

Product.md controls the **business and product structure**.

Therefore:

**Stitch = visual language**

**Product.md = product requirements**

The final website should combine both without allowing the visual reference to override required content, navigation, portfolio structure, service structure, calculator requirements, lead capture, or business logic.

# 20. Interaction & Motion

# 38. Product Principle

The website should follow one central principle:

> **Show the quality before asking for the enquiry.**

A visitor should be able to browse the portfolio, understand the
studio's approach, see proof of execution, estimate the likely budget
and then confidently choose to speak to a designer.

The final experience should make the studio owner feel:

**"I can send this website to a client and let the website sell the
quality of our work before I ever speak to them."**
